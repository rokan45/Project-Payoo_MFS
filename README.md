# 💳 Payoo_MFS

A simple Mobile Financial Service (MFS) web application that simulates real-world digital transactions with a clean and user-friendly interface.


## 🚀 Live Demo

https://rokan45.github.io/Project-Payoo_MFS/



## 📌 Features

* ➕ Add money to balance
* 💸 Cash out funds
* 🔁 Transfer money to other users
* 🎁 Get bonuses
* 🧾 Pay bills
* 📊 Transaction history *(In Progress)*


## 🛠️ Technologies Used

* **HTML5** – Structure and semantic layout
* **Tailwind CSS** – Utility-first styling
* **DaisyUI** – UI components
* **Vanilla JavaScript** – Dynamic functionality


## 🧠 Project Purpose

This project was built to:

* Practice frontend development fundamentals
* Strengthen JavaScript logic building
* Simulate real-world financial workflows
* Build a clean and responsive UI

## ⚙️ How to Run Locally

1. Clone the repository:

```
git clone https://github.com/rokan45/Project-Payoo_MFS.git
```

2. Navigate to the project folder:

```
cd Project-Payoo_MFS
```

3. Open `index.html` in your browser
